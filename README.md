# ⚗️ Hóa Học 8 → 12 (ChemMaster Mobile)

> Ứng dụng web học Hóa học từ mất gốc (lớp 8) đến lớp 12 và ôn thi tốt nghiệp THPT, tối ưu trải nghiệm chạm vuốt trên thiết bị di động (Mobile).

## 🌟 Tính Năng Nổi Bật

- **Lộ trình 5 chặng bài bản:**
  - **Chặng 1:** Mất gốc & Nền tảng (Lớp 8-9) - Nguyên tử, hóa trị, số mol, phân loại chất.
  - **Chặng 2:** Bước đệm & Cấu trúc (Lớp 9-10) - Dãy hoạt động kim loại, bảng tuần hoàn, oxi hóa - khử.
  - **Chặng 3:** Vô cơ & Đại cương Hữu cơ (Lớp 11) - pH, axit-bazơ, hidrocacbon.
  - **Chặng 4:** Trọng tâm THPT (Lớp 12) - Este, lipit, cacbohidrat, amin, amino axit, polime.
  - **Chặng 5:** 4 Định luật bảo toàn vạn năng (BTKL, BTNT, BTĐT, BTe).
- **Bộ công cụ thực hành:**
  - ⚖️ Máy tính số mol, khối lượng, thể tích khí (chuẩn cũ 22.4L & chuẩn mới 24.79L).
  - 🧪 Máy tính nồng độ mol $C_M$.
  - 🔬 Bảng tuần hoàn bỏ túi: tra cứu Z, nguyên tử khối, hóa trị tức thì.
  - 💧 Bảng tính tan & bài ca hóa trị, thần chú dãy kim loại.
- **Luyện tập:**
  - Trắc nghiệm kiểm tra độ hiểu bài có giải thích chi tiết.
  - Lưu tiến độ học tập tự động vào bộ nhớ trình duyệt (`localStorage`).
  - Giao diện Dark/Light mode thân thiện cho mắt khi học đêm.

## 🚀 Cách Chạy Ứng Dụng

### 1. Chạy trực tiếp với Python:
```bash
python3 -m http.server 8080
```
Sau đó mở trình duyệt và truy cập `http://localhost:8080`.

### 2. Mở trực tiếp trên Mobile:
Chỉ cần mở file `index.html` bằng bất kỳ trình duyệt nào trên điện thoại.
